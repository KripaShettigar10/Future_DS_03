# Future_DS_03
🛒 Marketing Funnel & Conversion Performance Analysis

Future Interns — Task 3 | Data Science & Analytics

📌 Project Overview

This project analyzes e-commerce customer behavior using event data to understand product views, cart additions, purchase activity, and product-category performance. The aim is to identify potential drop-off points in the shopping journey and provide data-driven business recommendations.

🎯 Objectives

- Analyze e-commerce event activity.
- Examine the shopping funnel and potential conversion drop-offs.
- Identify product categories with high purchase activity.
- Compare average product prices across event types.
- Build an interactive Power BI dashboard.

📂 Dataset

- Dataset: E-commerce Behavior Data from Multi-Category Store
- Period: October 2019
- Data used: Approximately 100,000 event records
- Key fields: Event time, event type, product ID, category, brand, price, user ID, and session ID.

Note: The analysis uses a sample of the original dataset. Marketing-channel and campaign fields are not available.

🛠️ Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib
- Jupyter Notebook
- Microsoft Power BI

📊 Analysis Performed

- E-commerce shopping funnel analysis
- Top 10 product categories by purchase events
- Category purchase-to-view event ratios
- Average product price by event type
- Daily purchase-event trend
- Interactive Power BI dashboard with KPI cards and charts

💡 Key Findings

- The dataset sample contains 99,983 events across 24,382 sessions.
- Product view events are much more frequent than cart-addition events.
- The session-level funnel highlights a substantial drop-off between viewing products and adding them to the cart.
- Product-category and price analyses help identify patterns for further business investigation.

🚀 Business Recommendations

- Improve product descriptions, images, and pricing transparency.
- Make the add-to-cart process more visible and convenient.
- Review category-level purchase activity to support inventory and promotional decisions.
- Investigate customer behavior further using more detailed conversion and marketing data.

📈 Deliverables

- Jupyter Notebook analysis
- Dataset sample
- Project report (PDF)
- Power BI dashboard and screenshot
- Data visualizations

⚠️ Limitations

The dataset does not include explicit marketing-channel or campaign information. Therefore, channel-specific performance cannot be measured. Purchase-to-view ratios are based on event counts and should not be interpreted as unique-customer conversion rates.
